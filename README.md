## О проекте
**HTML Layout Project** — учебный frontend-проект, направленный на практику верстки статических веб-страниц с использованием чистого HTML.
Проект демонстрирует базовую структуру сайта, семантическую разметку и организацию контента без использования серверной логики и фреймворков.

## Основной функционал

**В проекте реализовано:**
- Главная страница сайта
- Навигационное меню
- Контентные секции (карточки товаров)
- Меню пользователя
- Страница контактов с формой обратной связи
- Логичная структура интерфейса

Проект может использоваться как основа для дальнейшего развития с добавлением CSS и JavaScript.
